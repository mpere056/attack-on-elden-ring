# Attack on Elden Ring

Attack on Titan Tribute Game 2's ODM gear inside Elden Ring. Both real games run at once: AoTTG2
runs hidden and handles your movement and blades; Elden Ring draws the world and runs its enemies.

**Status: milestone 0, setting up. Nothing works yet.**

Unofficial fan project, not affiliated with FromSoftware, Bandai Namco or the AoTTG2 team.
Built with AI assistance (Claude Code).

## Requirements
- Windows x64
- Elden Ring, Steam, App Ver. **1.17.1** (`eldenring.exe` 2.7.1.0). Other versions are refused.
- AoTTG2 **1.2.3**
- me3 (Mod Engine 3) v0.13.0, BepInEx 6 bleeding edge build 788 (IL2CPP x64)

**Offline only.** Elden Ring starts through me3 without Easy Anti-Cheat and with its own save
file. AoTTG2 runs in offline single-player; the plugin blocks online connections.
